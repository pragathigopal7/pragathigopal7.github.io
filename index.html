Selected work

Retail data pipeline

A streaming orders pipeline that takes events from Kafka, enforces a schema contract at the edge, and builds bronze, silver, and gold tables in DuckDB over Parquet. It handles duplicate deliveries, late events, and malformed payloads, and quality gates stop a bad feed before it reaches analytics.

Python, Kafka (Redpanda), DuckDB, Parquet, Pydantic, GitHub Actions

Orders API in Go

A REST service for a product catalog, inventory, and the order lifecycle. Idempotency keys make retried orders safe even when they arrive at the same time, stock is reserved inside one transaction so nothing oversells, and a transactional outbox delivers events at least once and in order per order. Keyset pagination keeps lists stable while data changes.

Go standard library, PostgreSQL, JWT, OpenAPI 3.1, Docker, Kubernetes (Kustomize), GitHub Actions

Codebase Q&A agent on Amazon Bedrock AgentCore

An agent that answers questions about a Java Spring Boot codebase and cites file and line references for every claim, built for engineers working through legacy migrations. The focus is measuring accuracy: retrieval is evaluated live, and a local demo runs offline or against a local model.

Python, Amazon Bedrock AgentCore, Strands Agents SDK, Ollama

LLM eval harness

A dependency free Python harness that runs a model over a test set, scores each answer with reference metrics or an LLM judge, tracks latency, tokens, and cost, and fails CI when a prompt or model change makes results worse.

Python standard library, Anthropic and OpenAI compatible APIs
