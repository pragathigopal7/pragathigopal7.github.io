# pragathigopal7.github.io

Source for my personal site, served by GitHub Pages at https://pragathigopal.com (also reachable at https://pragathigopal7.github.io, which redirects there). The `CNAME` file holds the custom domain; don't delete it.

It's a single hand written HTML page with no build step. Edit `index.html`, commit, and push to `main`; GitHub Pages republishes in about a minute.

To preview locally:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
